# MySoftware

Private Claude Code plugin for running our Shopify store: planning, test-first changes,
reviews, Shopify know-how (themes, apps, Functions, Admin API scripts) and guardrails that
stop accidental changes to the live store.

Status: Phase 0 (project skeleton). See [PLAN.md](PLAN.md) for the plan and phases.

## Development

```bash
npm ci --ignore-scripts
npm run lint
npm test
```
